College ERP Management System

About Project

College ERP is a web-based College Management System developed using JSP, Servlet, JDBC and MySQL.

Technologies Used

- Java
- JSP
- Servlet
- JDBC
- MySQL
- HTML
- CSS
- Bootstrap 5.3.8
- Apache Tomcat

Admin Features

- Admin Login and Logout
- Student Management
- Teacher Management
- Course Management
- Attendance Management
- Fees Management
- Examination Management
- Student Login Management

Student Features

- Student Login and Logout
- Student Dashboard
- My Profile
- My Attendance
- My Fees
- My Results
- Print Result
- Change Password

Database

Database Name: college_erp

Installation

1. Install JDK, XAMPP and Apache Tomcat.
2. Import the MySQL database using phpMyAdmin.
3. Open the project in VS Code.
4. Configure JDBC connection.
5. Run the project using Apache Tomcat.
